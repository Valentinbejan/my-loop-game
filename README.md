# Kingdom Loop and Retro Sci-Fi Experiments

Source from the Kingdom Loop Godot project and custom retro sci-fi gameplay extensions.

## Contents and current limits

The Godot project is at loop-game/project.godot. Custom Python extension modules remain at 3d-2d-game/Renpystein_3D-1.0-pc/game/retro_*.py. The separately obtained Renpystein base game, its original integration scripts/libraries, Ren'Py SDK, game media, asset packs, toolchains, and historical snapshots are omitted. The custom modules were absent from the supplied original base archive. This is a source selection, not a complete runnable distribution; integration requires the separately licensed base and local project resources.

This is a curated public copy of the local project. Publication documentation
exists only in this separate copy. The original project is not modified.
Imported source files retain their original relative paths and contents.
No prior Git history, credentials, local caches, backups, or bundled tools
are included.
