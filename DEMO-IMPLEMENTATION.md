# Kingdom Loop demo implementation

Target: full-system 2–3 hour Windows demo, four regions, camp-to-kingdom progression, family and heirs, ten-person final party, tutorial, no audio. All individual art frames are 64×64. New work uses AI art + Pixel Snapper + Aseprite, with replaceable temporary actors.

Milestones: visual benchmark; connected town/adventure/combat/save loop; complete simulation and progression; full UI/tutorial; playthrough and visual review; Windows delivery.

Acceptance: playable beginning-to-victory, meaningful defeat/recovery, paused/offline calendar invariant, stable saves, full UI actions, and documented asset/scene reviews targeting at least 8.5/10. Scores must record evidence and remaining defects honestly.
